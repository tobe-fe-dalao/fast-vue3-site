# アーキテクチャ進化の概要

Fast Vue3 は **Polyrepo（単一リポジトリ）** から **Monorepo（マルチパッケージリポジトリ）** への完全なアーキテクチャ進化を経験しました。

## タイムライン

```
2022 ～ 2024         2025 Q1              2025 Q2 ～ 現在
────────────        ────────────         ────────────────
 Polyrepo フェーズ    アーカイブフェーズ    Monorepo フェーズ
 単一アプリ           polyrepo ブランチ     main ブランチ再構築
 標準化・最適化        履歴保存              マルチアプリプラットフォーム
```

## 2 つのアーキテクチャ

| ブランチ   | アーキテクチャ | 説明                               |
| ---------- | -------------- | ---------------------------------- |
| `polyrepo` | Polyrepo       | 旧アーキテクチャ（アーカイブ済み） |
| `main`     | Monorepo       | 新アーキテクチャ（継続的に進化）   |

## なぜ移行したか

Polyrepo の主要な問題点：

1. **バージョン分散** — 依存バージョンが単一の `package.json` に混在
2. **コード再利用不可** — 複数 UI 対応にはプロジェクト全体のコピーが必要
3. **設定の重複** — ESLint・TypeScript・Vite 設定を毎回書き直し
4. **パッケージ境界なし** — `src/` 下にすべてが混在
5. **スケーラビリティ不足** — 新技術スタック追加にはフォークが必要

Monorepo が解決する問題：

- **バージョン統一管理** — pnpm workspace catalog
- **インフラ共有** — `packages/*` を一度書いて全アプリで再利用
- **スケーラビリティ** — `apps/` に追加するだけで新 UI エコシステムに対応
- **明確な境界** — 各パッケージが単一の責任を持つ
