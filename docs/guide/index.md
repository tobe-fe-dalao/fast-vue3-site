# Fast-Vue3

[Fast-Vue3](https://github.com/tobe-fe-dalao/fast-vue3)，是基于 Vite 7 + Vue 3.5 + TypeScript 5.9 + Pinia 3 + 多 UI 组件库（Element Plus / Ant Design Vue / Naive UI / TDesign / Arco Design / DevUI / iDux）构建的 PC 端快速开发脚手架。

## 特点

### 最新技术栈

- 基于 Vue 3.5 + Vite 7 + TypeScript 5.9 技术栈，搭配 Pinia 3 状态管理、Vue Router 4 文件路由
- 精选社区 star 和满意度均不错的 UI 框架和 Vite 插件，保持与官方 API 同步更新

### 基于 TypeScript

- TypeScript 5.9 全面类型支持，明确的类型定义减少维护成本和团队沟通时间
- 使用 `vue-tsc` 进行构建前类型检查

### 多 UI 组件库集成

- 集成 Element Plus、Ant Design Vue、Naive UI、TDesign、Arco Design、DevUI、iDux 等 7+ 组件库
- 通过 `unplugin-vue-components` 和 `unplugin-auto-import` 实现按需自动导入

### 开发体验优化

- UnoCSS 原子化 CSS，替代传统 Tailwind
- 文件路由（unplugin-vue-router），无需手动注册路由
- ESLint Flat Config + Prettier + Stylelint 全链路代码规范
- Husky + Lint-Staged + Commitizen 规范化提交流程
- Plop 模板生成器，一键创建页面、组件、Store

### 通俗易懂的文档

- 基于 VitePress 构建的文档，更快，更便捷
- 更快的热更新
