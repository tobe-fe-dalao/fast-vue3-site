# @fast-vue3/preferences

适用分支：`main`。路径：`packages/preferences`。

usePreferences 管理主题、主色、侧栏和布局偏好。

支持 light/dark/auto、主色、侧栏宽度/折叠、header 高度、标签页、面包屑、语言和辅助颜色模式。isDark 结合系统偏好计算，并将主题状态同步到 DOM。
